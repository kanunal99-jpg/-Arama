# Career Engine v1

## Core loop

Measure -> Find Gap -> Teach -> Apply -> Test -> Update Score -> Repeat

## Skill score

Each skill score is composed of:
- knowledge: 25%
- application: 30%
- scenario: 25%
- evidence: 20%

A CV claim alone never counts as verified evidence.

## Priority

Gap priority combines:
- skill gap
- target-role requirement
- career impact
- developability

## Adaptive learning

- Strong skill: skip basic teaching and move to application.
- Medium skill: short teaching -> application -> test.
- Weak skill: fundamentals -> example -> guided practice -> independent practice -> test.

## Reassessment

Every completed learning cycle updates the skill score and creates a score-history point. The next learning action is selected from the highest career-impact remaining gap.
